DB Connection Tester

Esta instalação inclui a interface gráfica e a CLI dbct.exe, com o runtime necessário. Não é preciso instalar .NET separadamente.

Terminal

Se a opção de PATH foi habilitada, abra um novo terminal. Terminais já abertos mantêm o ambiente anterior.

dbct --help
dbct run --help
dbct history list --data-dir "C:\Meus dados\DBCT" --format json

Use where.exe dbct para identificar qual instalação será executada. Instalações por usuário e por máquina podem coexistir; use o caminho completo para escolher uma delas.

Dados e credenciais

Dados ficam por padrão em %LOCALAPPDATA%\DBConnectionTester. O aplicativo também pode usar armazenamento compartilhado, portátil ou personalizado. O instalador não seleciona, migra ou remove bancos. Instalar para todos os usuários não torna o histórico compartilhado.

--data-dir indica a pasta do armazenamento da aplicação; caminhos relativos usam o diretório corrente. Para senhas use --password-env NOME_DA_VARIAVEL ou --password-stdin. Não forneça senhas nos argumentos.

Atualização e remoção

Encerre os executáveis desta instalação antes de atualizar, reparar ou remover. O instalador não encerra processos à força. Cada contexto possui manutenção própria. Dados, relatórios e preferências são preservados.

Na desinstalação são removidos os arquivos registrados, atalhos e a entrada de PATH deste contexto. Arquivos adicionais criados por você não são removidos recursivamente.

Dependências externas

SQL Anywhere requer driver ODBC x64 instalado separadamente. Autenticação Windows usa a identidade que executa o aplicativo. Bibliotecas nativas dos executáveis single-file podem ser extraídas em diretório temporário gravável.

Este MSI inicial não possui assinatura Authenticode. Confira o SHA-256 e obtenha o instalador pelo canal oficial do projeto.
