# Códigos de sugestão

| Código | Ação |
|---|---|
| `DBT-FIX-DNS-001` | Confirme o host, sufixo DNS e servidor DNS configurado. |
| `DBT-FIX-NET-001` | Confirme rota, VPN, firewall e disponibilidade do destino. |
| `DBT-FIX-ICMP-001` | Confirme se ICMP está permitido no host e nos firewalls. |
| `DBT-FIX-PORT-001` | Confirme host, porta, serviço em execução e firewall. |
| `DBT-FIX-AUTH-001` | Confirme usuário, senha e método de autenticação. |
| `DBT-FIX-DB-001` | Confirme o nome do banco e o acesso do usuário. |
| `DBT-FIX-TIMEOUT-001` | Verifique latência e saúde antes de elevar o timeout. |
| `DBT-FIX-TLS-001` | Revise certificado, confiança, nome do servidor e TLS. |
| `DBT-FIX-PERM-001` | Conceda somente o necessário para conectar e executar `SELECT 1`. |
| `DBT-FIX-CAPACITY-001` | Revise limite e consumo de conexões. |
| `DBT-FIX-DRIVER-001` | Instale ou selecione o driver e a arquitetura corretos. |
| `DBT-FIX-SQLITE-001` | Confirme caminho, acesso, formato e integridade do arquivo. |
| `DBT-FIX-COLLECT-001` | Analise detalhe técnico e código original do provider. |
